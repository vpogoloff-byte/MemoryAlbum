# MemoryAlbum

Мой первый самостоятельный проект с графическим интерфейсом на C# (Windows Forms). 

Это приложение-альбом с воспоминаниями. Идея в том, чтобы собрать важные моменты (скриншоты переписок, игр, фотографии) и разложить их по месяцам.

## Что уже реализовано:
- Стартовый экран с приветствием.
- Меню с выбором из 12 месяцев.
- Экран просмотра контента (пока с одной тестовой картинкой) и кнопка возврата в меню.
- Навигация между панелями без перезапуска приложения.

## Что в планах:
- Добавить списки (`List<T>`) для листания нескольких картинок в каждом месяце.
- Наполнить приложение реальными скриншотами и текстами.
- Добавить зимний дизайн (анимации снега, гифки).

## Технологии:
- C#
- .NET (Windows Forms)
